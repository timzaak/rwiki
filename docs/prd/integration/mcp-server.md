## 2. 范围界定

### 2.1 包含功能

- **MCP 服务端能力**：在现有单二进制服务内提供 MCP 协议入口（仅 Streamable HTTP 传输形态），供 MCP 客户端（Claude Code、Cursor 等 Agent 工具）远程连接，不引入第二个进程。
- **公开访问**：MCP 入口不要求任何凭据——不受 API Token 保护，也不套用来源 IP 白名单；请求携带 API Token 时照常处理，不影响访问结果。
- **按频道寻址的入口**：每个已配置频道对应一个 MCP 入口地址（地址中包含该频道标识）；频道未在配置中定义时，对应入口不可用；不提供不含频道标识的入口。
- **知识库问答工具**：面向 Agent 的 RAG 问答，返回带来源引用的非流式完整回答；检索范围与回答口径和公开聊天能力一致（查询改写、混合检索、rerank、引用）。
- **知识检索工具**：返回与查询相关的、按相关性排序的原始知识片段列表，每条片段带来源信息。
- **频道隔离**：工具调用必须携带 `channelId`，校验与数据隔离语义和公开聊天能力一致；工具调用的检索频道由该参数决定。
- **频道标识格式校验**：服务启动时校验配置中所有频道标识符合允许的字符规则，不合规时拒绝启动并指明该标识。
- **配置管理**：通过配置文件控制 MCP 能力启用，省略配置段即关闭。

### 2.2 不包含功能 (Out of Scope)

- stdio 子进程传输模式。
- MCP OAuth、动态客户端注册等 MCP 原生鉴权机制（入口为公开能力，无需鉴权）。
- 访问限流与配额：属全局能力，另行立项；MCP 匿名调用产生的 LLM 成本与公开聊天入口同级暴露，不另设防护。
- 按频道或按客户端的差异化访问控制（所有已配置频道对所有客户端同等公开）。
- 以入口地址绑定并限制检索频道（入口地址中的频道标识仅作寻址，见 4.1）。
- 流式回答或工具执行进度通知（MCP 工具调用返回单结果）。
- 服务端多轮会话记忆（MCP 问答工具每次调用独立，不存储对话历史）。
- 文档管理操作（上传、列表、删除、发布/取消发布）暴露为 MCP 工具。
- 聊天反馈（赞/踩）、推荐问题等其余聊天能力的 MCP 暴露。
- 前端页面或管理后台变更（含在文档站展示各频道 MCP 入口地址）。
- MCP 客户端侧的接入文档与分发（随使用文档发布，不属产品能力范围）。

### 2.3 依赖项

- **多频道隔离**：依赖 `docs/prd/integration/support-multiple-website.md` 的 `channelId` 校验与数据隔离规则，以及其 §4.1 的频道标识格式规则（URL-safe：字母、数字、连字符、下划线）与 §5.1 的启动校验要求；主站"通过 URL path 后缀访问指定频道"（US-INTG-007）是 MCP 按频道寻址的同形态先例。
- **检索与回答管线**：依赖既有聊天能力基线——查询改写（`docs/prd/chat/query-rewrite.md`）、关键词与混合检索（`docs/prd/document/keyword-search-support.md`）、rerank 精排（`docs/prd/core/rerank-investigation.md`）、上下文组装与引用（`docs/prd/chat/chat-context-prompt-assembly.md`）。

## 3. 需求概述

### 3.1 功能描述

RWiki 面向公共文档建设：知识库中的已发布内容本就通过公开聊天入口对外开放。本能力把同一知识库的问答与检索以 MCP（Model Context Protocol）工具的形式公开暴露，使 Claude Code、Cursor 等 Agent 工具只需填入某个频道的 MCP 入口地址——无需申请、保管或配置任何密钥——即可把 RWiki 作为知识库工具使用。知识库从"给人用的问答服务"扩展为"给 Agent 用的工具服务"，接入摩擦与公开聊天入口持平，不改变公开聊天、Widget 与文档管理等既有能力的行为。

### 3.2 关键特性

- **公开可达**：MCP 入口与公开聊天入口同一暴露级别，仅消费频道已发布内容，不要求凭据。
- **按频道寻址**：每个已配置频道有独立的 MCP 入口地址，客户端按频道组织连接；未配置频道无入口。
- **只读工具面**：仅暴露问答与检索两个只读工具，管理操作不进入 MCP 工具清单。
- **单服务挂载**：MCP 能力内嵌于现有服务，启用后随服务一起可用，无独立部署单元。
- **回答口径一致**：MCP 问答与公开聊天使用同一检索与回答管线，同一问题在同一频道得到同源回答与引用。
- **默认关闭**：未配置 MCP 段的部署完全不暴露该能力。
- **频道标识安全前置**：频道标识在配置加载时即保证为安全的单一地址段，入口地址无需额外补救。

## 4. 业务规则与状态

### 4.1 业务规则

- **访问规则**：MCP 入口为公开能力，不要求任何凭据；请求携带 API Token 时不校验、不拒绝，照常处理；不套用来源 IP 白名单。
- **入口寻址规则**：每个已配置频道对应一个 MCP 入口地址；频道标识未在配置中定义时，对应入口不可用（不完成协议握手、不返回工具清单）；不提供不含频道标识的入口。入口地址中的频道标识仅用于寻址与有效性校验，**不限定**该连接上工具调用的检索频道。
- **工具面边界**：MCP 工具清单仅含知识库问答与知识检索；工具调用均为只读，不产生知识库内容变更、不写入会话反馈。
- **频道规则**：工具调用必须携带有效 `channelId`，该参数决定本次调用的检索频道；缺失、未定义均拒绝，不回退到任何默认频道（含不回退到入口地址中的频道）；检索与问答仅发生在该频道的已发布文档集合内；单次调用不可见、不可枚举其他频道内容。
- **频道标识格式规则**：沿用 `support-multiple-website.md` §4.1 的字符规则（字母、数字、连字符、下划线）；服务启动时校验配置中全部频道标识，任一不合规即拒绝启动并指明该标识；该校验不以 MCP 是否启用为条件。
- **回答形态**：问答工具返回一段完整非流式回答，来源引用仅指向该频道已发布文档；检索工具返回按相关性排序的片段列表，每条带来源信息。
- **单轮语义**：每次工具调用独立完成，服务端不保存 MCP 调用之间的对话历史。
- **启用规则**：MCP 能力由配置段控制，配置段存在即启用，省略即关闭；关闭时不影响现有任何能力。
- **异常口径**：频道无已发布文档、频道标识无效等业务异常沿用公开聊天能力的既有提示口径。

### 4.2 关键状态与异常

- **能力未启用**：配置省略 MCP 段 → 所有频道的 MCP 入口不可用，服务其余功能正常。
- **入口频道未配置**：入口地址中的频道标识未定义 → 入口不可用，不返回任何工具或知识库内容。
- **频道标识不合规**：配置中任一频道标识含允许字符以外的字符 → 服务启动失败并指明该标识。
- **正常调用**：频道有效且有已发布文档 → 返回回答或片段列表。
- **工具参数频道缺失/未定义**：拒绝调用并提示频道不存在或不可用。
- **频道无可用文档**：拒绝问答调用并提示当前频道没有可用文档。
- **检索无相关内容**：返回空结果并正常结束，不视为错误。

## 5. 功能需求

### 5.1 核心需求

1. **MCP 服务端能力**
   - 支持主流 MCP 客户端以 Streamable HTTP 远程连接某频道的入口地址并完成协议握手，连接过程不要求任何凭据。
   - 支持工具发现：客户端可列出 RWiki 提供的工具及用途说明。
   - 支持工具调用：客户端可调用问答与检索工具并获得结果。

2. **公开访问与入口寻址**
   - MCP 入口不接入 API Token 鉴权与 IP 白名单；携带 Token 的请求结果与不携带时一致。
   - 每个已配置频道有独立入口地址；未配置频道的入口不可用；不提供不含频道标识的入口。

3. **知识库问答工具**
   - 入参为问题与目标 `channelId`。
   - 在该频道已发布文档集合内执行检索增强问答，返回带来源引用的完整回答。
   - 业务异常（频道无效、频道无文档）返回明确提示。

4. **知识检索工具**
   - 入参为查询与目标 `channelId`。
   - 返回按相关性排序的原始知识片段列表，每条片段带来源信息，仅来自该频道已发布文档。
   - 无相关内容时返回空结果。

5. **频道标识格式校验**
   - 服务启动时校验配置中全部频道标识符合允许的字符规则。
   - 不合规时拒绝启动，错误信息指明该频道标识与允许的字符规则。
   - 校验独立于 MCP 启用状态。

6. **配置管理**
   - 配置文件提供 MCP 配置段，控制能力启用；沿用项目"省略即关闭"的配置段惯例。
   - 配置项细节由技术设计文档承载，不写入本 PRD。

### 5.2 验收目标

- 配置启用后，不带任何凭据连接某已配置频道的 MCP 入口地址，客户端连接成功并发现问答与检索两个工具；携带 API Token 连接得到相同结果。
- 连接未配置频道的入口地址或不含频道标识的入口地址时，连接失败且不返回任何知识库内容。
- 配置省略 MCP 段时所有频道入口不可用，现有聊天与 Widget 功能不受影响。
- 配置中存在含斜杠、空格等非允许字符的频道标识时，服务启动失败并指明该标识；全部合规时正常启动；该行为与 MCP 段是否存在无关。
- 问答工具对指定频道问题返回带引用的完整回答，引用仅指向该频道已发布文档；与公开聊天能力在同频道同问题上的检索范围口径一致。
- 在某频道入口建立的连接上，以另一已配置频道的 `channelId` 调用工具，结果仅来自参数指定的频道。
- 检索工具返回带来源的排序片段；无相关内容时返回空结果。
- `channelId` 缺失或未定义的调用被拒绝并返回明确提示，不回退到入口地址中的频道；频道无已发布文档时问答返回明确提示。
- MCP 调用之间不存在服务端保留的对话历史（重复调用互不影响）。

## 6. API 相关约束

**适用性**: 适用

- **能力范围**：以 MCP 协议暴露两个只读工具（知识库问答、知识检索）及标准工具发现能力；不暴露文档管理与反馈类操作。
- **访问控制原则**：MCP 入口为公开能力，不受 API Token 与 IP 白名单保护，与公开聊天入口同一暴露级别，仅消费各频道已发布内容；文档管理、运营数据等管理类接口仍受 API Token 保护，边界不变。
- **数据边界**：工具入参 `channelId` 是 MCP 工具调用的频道数据隔离边界，语义与公开聊天能力一致；入口地址中的频道标识与 `channelId` 均为公开标识，不用于鉴权，前者仅用于寻址与有效性校验。
- **兼容性要求**：MCP 入口仅按频道寻址提供，不提供不含频道标识的入口；曾使用无频道入口地址的客户端需改用频道入口地址（可同时移除 Token 配置）。工具清单、工具参数与返回结构保持不变，已接入客户端的工具调用无需改动。现有公开聊天、Widget、文档管理接口行为不变。频道标识格式校验对使用 TOML 裸键定义频道的既有配置无影响（裸键字符集与允许规则一致）。
- **接口细节**：MCP 入口地址形态、工具参数与返回结构由技术设计文档承载，不写入本 PRD。

## 7. 前端/交互约束

**适用性**: 不适用

本功能为纯后端集成能力，调用方是 MCP 客户端（Agent 工具），无前端页面、组件或交互变更；在文档站展示各频道 MCP 入口地址不在范围（见 2.2）。

## 8. 已确认决策

- **仅 Streamable HTTP 传输**：MCP 端点挂载于现有单二进制服务，不提供 stdio 子进程模式。
- **公开免鉴权**：MCP 入口不要求任何凭据，不套用 API Token 与 IP 白名单；匿名调用产生的 LLM 成本与公开聊天入口同级暴露；访问限流与配额作为全局能力另行立项，出现需要承载非公开内容频道的部署场景时重开决策。
- **按频道寻址、参数优先**：每个已配置频道一个入口地址，未配置频道入口不可用，不提供无频道入口；入口地址中的频道段仅作寻址与有效性校验，不限定检索范围；工具入参 `channelId` 保持必填并决定实际检索频道。需要按入口隔离检索频道时重开决策。
- **频道标识启动强制校验**：沿用已发布字符规则（字母、数字、连字符、下划线），不合规的频道标识导致服务拒绝启动并指明；校验不以 MCP 启用为条件。需要放宽字符集（如非 ASCII 频道标识）时重开决策。
- **首版单轮语义**：MCP 问答工具每次调用独立完成，服务端不存储 MCP 调用之间的对话历史；多轮会话记忆与流式回答不在当前范围，用户提出相关需求时重开决策。
