## 2. 范围界定

### 2.1 包含功能

- 在聊天界面空状态（无对话消息时）展示预设推荐问题按钮
- 管理员通过配置文件定义推荐问题内容
- 后端提供 API 返回当前配置的推荐问题
- 用户点击按钮后等同于手动输入并发送问题，走现有 SSE 流式回答流程
- 点击后按钮消失，进入正常对话模式
- Widget 嵌入场景优先使用 JS 配置传入推荐问题；未配置或语言无匹配时回退调用后端 `/api/chat/suggestions`（与主站一致）

### 2.2 不包含功能 (Out of Scope)

- 动态推荐（基于知识库内容自动生成推荐问题）
- 回复后展示后续推荐问题
- 推荐问题内容的 LLM 预生成或预缓存
- 管理界面编辑推荐问题（v1 仅通过配置文件管理）
- 推荐问题的使用数据统计与分析
- 热更新推荐问题配置（需重启服务生效）

### 2.3 依赖项

- 现有聊天组件和 SSE 流式回答流程（`docs/prd/chat/chat-assistant.md`）
- Widget 嵌入能力（`docs/prd/integration/chat-widget-embeddable-js.md`）
- 后端配置文件管理（`backend/core/src/config.rs`）

## 3. 需求概述

### 3.1 功能描述

在聊天界面的空状态展示若干预设推荐问题按钮，帮助用户理解系统能力范围并快速开始对话。管理员通过配置文件按语言分组定义推荐问题内容，前端根据用户语言偏好展示对应语言的按钮。用户点击按钮后直接触发问答，降低首次使用门槛。

### 3.2 关键特性

- **空状态引导**：仅在无对话消息时展示，用户开始对话后自动消失
- **直接触发**：点击按钮等同于手动输入并发送，走现有 SSE 流式回答
- **静态配置**：管理员通过配置文件按语言分组预设推荐问题，`default` 为兜底语言
- **Widget 兼容**：嵌入场景优先使用 JS 配置；未配置或语言无匹配时回退后端 `/api/chat/suggestions`

## 4. 业务规则与状态

### 4.1 业务规则

- **展示时机**：仅当聊天消息列表为空（`messages.length === 0`）时展示推荐问题按钮
- **语言匹配**：前端根据浏览器语言（`navigator.language`）匹配推荐问题；精确匹配优先（如 `zh-CN`），其次前缀匹配（如 `zh`），均无匹配时使用 `default` 分组
- **点击行为**：点击推荐问题按钮等同于用户手动输入该问题并点击发送，走现有聊天流程
- **消失时机**：用户发送第一条消息后（无论通过点击按钮还是手动输入），推荐问题按钮消失
- **配置来源**：主站从后端 API 获取（携带语言参数）；Widget 优先读 JS 配置，未配置或语言无匹配时回退后端 API
- **数量限制**：每种语言建议 3-5 条，上限 10 条；超出上限的后端截断
- **文本长度**：单条问题文本建议不超过 50 字符
- **未配置行为**：未配置推荐问题或当前语言无匹配且无 `default` 时，空状态仅显示欢迎消息，不显示按钮区域

### 4.2 关键状态与异常

- **后端 API 不可达**：主站场景下若获取推荐问题失败，空状态仅显示欢迎消息，不影响手动输入
- **配置为空**：后端返回空数组时，不渲染推荐问题按钮区域
- **语言无匹配且无 default**：不渲染推荐问题按钮区域，空状态仅显示欢迎消息
- **Widget 未配置**：Widget 未传入 `suggestedQuestions` 时，空状态仅显示欢迎消息

## 5. 功能需求

### 5.1 核心需求

1. **后端配置**
   - 管理员在配置文件 `[chat]` 段新增 `suggested_questions` 字段，值为按语言分组的映射（locale key → 字符串数组），`default` 键为兜底
   - 应用启动时加载到内存，运行期间不变

2. **后端 API**
   - 提供返回推荐问题的端点，支持按 locale 参数筛选；无匹配 locale 时返回 `default` 分组
   - 未配置时返回空数组

3. **前端展示**
   - 聊天空状态时在欢迎消息下方渲染推荐问题按钮，垂直排列
   - 使用现有 Button 组件，`variant="outline"` 样式
   - 点击按钮调用现有 `sendMessage` 函数发送问题

4. **Widget 支持**
   - WidgetConfig 新增 `suggestedQuestions` 可选字段，支持按语言分组或直接字符串数组（向后兼容）
   - Widget 空状态根据浏览器语言展示匹配的推荐问题按钮
   - 优先使用配置值；未配置或语言无匹配时回退调用后端 `/api/chat/suggestions`

### 5.2 验收目标

- 管理员在配置文件中按语言分组添加推荐问题并重启服务后，聊天空状态展示匹配当前语言的按钮
- 浏览器语言为中文时展示中文推荐问题，为英文时展示英文推荐问题，均无匹配时展示 `default` 分组
- 用户点击任意推荐问题按钮，该问题被发送到聊天流并获正常流式回答
- 未配置推荐问题时，聊天空状态仅显示欢迎消息，不影响正常使用
- Widget 传入 `suggestedQuestions` 后，Widget 空状态展示对应按钮
- Widget 未传入 `suggestedQuestions` 时，空状态仅显示欢迎消息

## 6. API 相关约束

**适用性**: 适用

- **能力范围**：新增返回推荐问题的端点，支持按 locale 参数筛选；不修改现有端点
- **访问控制**：该端点公开访问，无需鉴权（推荐问题不属于敏感数据）
- **兼容性**：不修改现有接口行为和参数

---

## 7. 前端/交互约束

**适用性**: 适用

### 7.1 页面入口

- 落地页 `/` 聊天入口 — 空状态区域
- 全局浮动弹窗聊天 — 空状态区域
- Widget 聊天窗口 — 空状态区域

### 7.2 关键交互

- **空状态布局**：欢迎消息在上，推荐问题按钮在下方垂直排列
- **按钮点击**：点击后按钮组消失，问题文本出现在消息区域，系统开始流式回答
- **手动输入**：用户手动输入问题后，推荐问题按钮同样消失

### 7.3 状态反馈

- 推荐问题按钮加载中：无额外状态（按钮数据量极小，即时渲染）
- 按钮点击后：按钮组消失，消息区域显示用户问题和系统回答（复用现有流式渲染）

## 8. 已确认决策

- **静态配置**：v1 从配置文件读取，后续可扩展为动态生成
- **按语言分组**：配置按 locale 分组，`default` 为兜底；前端根据浏览器语言匹配展示
- **点击直接触发问答**：不做页面跳转，直接走现有聊天流程
- **仅空状态展示**：对话开始后不再显示
- **Widget 独立配置**：Widget 通过 JS 配置传入推荐问题，支持按语言分组或直接数组；未配置或语言无匹配时回退后端 `/api/chat/suggestions`
- **数量上限 10**：超出截断，建议 3-5 条
- **无需缓存**：配置已驻留在 AppConfig 内存中
- **无需预生成**：点击后走现有 SSE 流式回答
