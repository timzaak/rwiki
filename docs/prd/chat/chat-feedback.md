## 2. 范围界定

### 2.1 包含功能
- 每条 assistant 消息支持赞/踩反馈
- 反馈状态可切换（赞→踩、踩→赞、已选→取消）
- 反馈数据持久化到后端数据库
- Widget 和独立页面共用反馈逻辑
- 页面刷新后反馈状态恢复
- 反馈数据查询 API（需 Bearer Token 鉴权），供运营者查看和分析反馈记录

### 2.2 不包含功能 (Out of Scope)
- 文字反馈或评论
- 基于反馈的自动知识库优化
- 反馈频率限制
- 反馈数据导出

### 2.3 依赖项
- 聊天助手基础功能（`docs/prd/chat/chat-assistant.md`）
- SSE 流式聊天协议（同上）

## 3. 需求概述

### 3.1 功能描述
在 RAG 聊天中，用户对每条 AI 回答进行赞/踩反馈。反馈数据持久化到数据库，用于后续分析知识库文档覆盖和检索质量。当 RAG 召回分数过低导致回答质量不佳时，用户通过踩反馈标记，帮助运营者发现知识库盲区。

### 3.2 关键特性
- **反馈按钮**：每条 assistant 消息底部显示赞/踩按钮，streaming 完成后出现
- **状态可切换**：已选赞可切换为踩，反之亦然；可取消反馈
- **数据持久化**：反馈记录 session_id、message_id、用户消息、助手回答，支持 UPSERT
- **双入口一致**：Widget 和独立聊天页面行为完全一致

---

## 4. 业务规则与状态

### 4.1 业务规则
- **反馈时机**：仅在 streaming 完成后显示反馈按钮，streaming 中不显示
- **反馈数据**：每次反馈记录 session_id、message_id、feedback（like/dislike）、用户原始消息、助手回答全文
- **UPSERT 语义**：同一 session_id + message_id 只保留最新反馈，可覆盖修改
- **无需鉴权**：反馈提交 API 与聊天 API 一致，不需要额外鉴权
- **查询鉴权**：反馈查询 API 需要 Bearer Token 鉴权（与文档管理 API 一致），仅授权运营者可访问
- **数据用途**：仅用于知识库质量分析，不影响实时回答行为

### 4.2 关键状态与异常
- **反馈状态**：未反馈 → 已赞/已踩，可来回切换
- **API 失败**：反馈按钮显示错误提示（如网络异常），不静默失败
- **离线场景**：反馈仅在在线状态下可用，不缓存离线反馈

## 5. 功能需求

### 5.1 核心需求
1. **反馈按钮展示**
   - 每条 assistant 消息底部显示赞/踩图标按钮
   - Streaming 中不显示，streaming 完成后出现

2. **反馈交互**
   - 点击赞/踩提交反馈，选中状态高亮
   - 可切换选择（赞→踩 或 踩→赞）
   - 可取消反馈（再次点击已选中按钮）

3. **数据持久化**
   - 反馈数据存储到 SQLite 数据库
   - UPSERT 语义保证同一消息只保留最新反馈

4. **双入口一致**
   - Widget 和独立页面共用反馈逻辑和 API

5. **反馈查询**
   - 提供反馈查询接口，支持按反馈类型筛选和分页
   - 需要 Bearer Token 鉴权，与文档管理 API 鉴权方式一致
   - 结果按时间倒序排列

### 5.2 验收目标
- 用户能在 streaming 完成后对任意 assistant 消息进行赞/踩反馈
- 反馈状态在页面刷新后恢复
- Widget 和独立页面反馈行为一致
- 反馈数据持久化到数据库，可手动查询分析

## 6. API 相关约束

**适用性**: 适用

- **能力范围**：新增反馈提交接口和反馈查询接口
- **访问控制**：
  - 反馈提交：不需要鉴权，与聊天接口保持一致
  - 反馈查询：需要 Bearer Token 鉴权，与文档管理接口一致
- **数据边界**：单知识库场景，无租户隔离需求
- **接口行为**：UPSERT 语义，同一消息反馈可覆盖更新

---

## 7. 前端/交互约束

**适用性**: 适用

### 7.1 页面入口
- 独立聊天页面（`/chat`）和 Widget 弹窗均适用

### 7.2 关键交互
- **反馈按钮位置**：assistant 消息气泡底部，右侧对齐
- **反馈触发**：streaming 完成后按钮出现，用户点击即提交
- **状态反馈**：选中按钮高亮，未选中恢复默认；API 失败时按钮旁显示错误提示
- **图标**：使用 ThumbsUp/ThumbsDown 图标风格

### 7.3 状态反馈
- 反馈提交中显示加载状态
- 反馈提交成功后按钮切换为选中状态
- 反馈提交失败显示重试提示

---

## 8. 已确认决策
- 采用用户反馈方案（赞/踩），不采用自动 RRF 分数阈值检测：RRF 值域压缩在 0.015~0.033，无法设有效阈值
- 仅支持赞/踩，不支持文字反馈：MVP 简化，降低反馈门槛
- 反馈提交 API 不需鉴权：与聊天 API 一致
- 反馈查询 API 需 Bearer Token 鉴权：与文档管理 API 一致，仅授权运营者访问
- UPSERT 语义：同一消息只保留最新反馈
