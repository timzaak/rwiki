## 故事 1：无需凭据即可把频道知识库接入 MCP 客户端 [US-INTG-010]

**优先级**: P0

**【用户故事】**
**作为**：Agent Integrator
**我希望**：只凭某个频道的 MCP 入口地址，不提供任何 Token 或凭据，就能把该频道的公开知识库接入 MCP 客户端
**从而**：Agent 工具无需申请、保管和配置密钥，就能直接调用公开文档知识库的问答与检索能力

**【验收标准】**

**场景 1：仅凭频道入口地址连接成功并发现工具**
```gherkin
Given 服务已启用 MCP 能力，且配置中存在频道 help_center
When 集成者在 MCP 客户端中添加 help_center 频道的 MCP 入口地址，不提供任何 Token 或凭据
Then 客户端连接成功，并展示 RWiki 提供的工具清单（知识库问答、知识检索）
```

**场景 2：沿用旧配置携带 Token 仍可连接**
```gherkin
Given 集成者沿用早前的客户端配置，请求中仍携带 API Token
When 客户端连接某已配置频道的 MCP 入口地址
Then 连接同样成功，携带的 Token 不影响结果
```

**场景 3：频道未配置时入口不可用**
```gherkin
Given 配置中不存在频道 foo
When 集成者在 MCP 客户端中添加 foo 频道的 MCP 入口地址
Then 客户端连接失败，入口不可用，不展示任何工具
```

**场景 4：无频道的旧入口已下线**
```gherkin
Given 集成者使用早前不含频道标识的旧 MCP 入口地址
When 客户端尝试连接
Then 连接失败，入口不可用
```

**场景 5：能力未启用**
```gherkin
Given 服务配置中未启用 MCP 能力
When MCP 客户端尝试连接任一频道的 MCP 入口地址
Then 连接失败，MCP 能力不可用
```

## 故事 2：通过问答工具获得带引用的完整回答 [US-INTG-011]

**优先级**: P0

**【用户故事】**
**作为**：Agent Integrator
**我希望**：Agent 在 MCP 客户端中调用 RWiki 问答工具，获得带来源引用的完整回答
**从而**：Agent 能基于指定频道的知识库回答问题并给出出处，无需人工查文档

**【验收标准】**

**场景 1：问答成功**
```gherkin
Given 指定频道下存在已发布文档且内容与问题相关
When Agent 调用问答工具，携带问题与该频道标识
Then 工具返回一段完整的非流式回答，回答中的来源引用仅指向该频道已发布文档
```

**场景 2：频道无可用文档**
```gherkin
Given 指定频道下没有任何已发布文档
When Agent 调用问答工具
Then 工具返回明确提示当前频道没有可用文档，不生成回答
```

**场景 3：频道标识无效**
```gherkin
Given 请求携带的频道标识未在服务配置中定义
When Agent 调用任一 MCP 工具
Then 调用被拒绝并提示频道不存在或不可用
```

## 故事 3：通过检索工具获取原始知识片段 [US-INTG-012]

**优先级**: P0

**【用户故事】**
**作为**：Agent Integrator
**我希望**：Agent 调用 RWiki 检索工具，获得与查询相关的原始知识片段及其来源信息
**从而**：Agent 可以不经 LLM 回答直接阅读、比对和引用知识库原文

**【验收标准】**

**场景 1：检索成功**
```gherkin
Given 指定频道下存在已发布文档且内容与查询相关
When Agent 调用检索工具，携带查询与该频道标识
Then 工具返回按相关性排序的知识片段列表，每条片段带来源信息，且仅来自该频道已发布文档
```

**场景 2：无相关内容**
```gherkin
Given 指定频道下已发布文档均与查询不相关
When Agent 调用检索工具
Then 工具返回空结果并正常结束，不报错
```
